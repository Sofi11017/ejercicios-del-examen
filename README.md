## 📝 Detalle de los Módulos Desarrollados

### 1. 🔥 Página 1: Ofertas Flash y Catálogo
- **Sección Flash Sale:** Temporizador de promociones, tarjetas de productos con descuentos destacados y banners visuales.
- **Integración con Catálogo:** Estilos y enlaces rápidos para categorías de productos en oferta.

### 2. 🌍 Página 2: Calculadora de Huella de Carbono
- Interfaz para estimar y visualizar la reducción de emisiones de CO₂ mediante el uso de productos ecológicos.
- Diseño modular integrable en el catálogo de productos.

### 3. ✉️ Página 3: Suscripción a Newsletter
- Formularios de captura de leads y suscripciones adaptados tanto para la página de inicio (`Index`) como para la página de `Contacto`.
- Estilos responsivos con validaciones de campos en CSS.

### 4. 🌱 Página 4: Impacto Ambiental (Nosotros)
- Bloque informativo que resalta métricas de sostenibilidad, consumo responsable y compromiso ecológico de la marca.

### 5. 📰 Página 5: Blog y Artículos
- Maquetación de cuadrícula de artículos informativos, consejos de vida sustentable y novedades ecológicas.
